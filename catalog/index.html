Agent HUD Style Catalog

Eight visual directions for the production panel, each rendering the same sample state: the drift badge, the page map with one missing route, kanban cards, and status pills. Every direction is driven by the same token set the real panel will use, so whichever you pick maps 1:1 onto implementation.

To choose, reply with the style id (e.g. midnight) — or name a blend, like "midnight layout with blueprint's map".

Built overnight as part of the agent-hud v1 build. The current shipped panel is the unstyled baseline; the chosen direction becomes panel/theme.ts tokens in a follow-up pass. All fonts shown are on Google Fonts.
